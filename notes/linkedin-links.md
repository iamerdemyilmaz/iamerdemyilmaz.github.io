# LinkedIn links with tracking parameters

Paste these into LinkedIn posts. Cloudflare Web Analytics reports the `utm_` parameters, so each post's visits can be told apart. The parameters do not change what the page shows.

Scheme: `utm_source=linkedin`, `utm_medium=social`, `utm_campaign=<series>`, `utm_content=<what was linked>`. For a new post series, change `utm_campaign` (for example `dfx-launch`, `dfx-weekly`, `gdt-course`).

## Reading the results

In Cloudflare Web Analytics, open the site, then filter by **UTM campaign** or **UTM content** to see visits per post. Referrer shows `linkedin.com` (or `lnkd.in` for shortened links) for visits without parameters, for example when someone shares your post.
